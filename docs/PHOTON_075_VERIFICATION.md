# PHOTON 0.7.5 RAW 광학 렌즈 선택·HDR 후보·처리 시간

2026-10-23. GPU 텍스처 처리와 RAW 광학 AUTO를 포함한 0.7.5 후보를 휴대폰에 설치했습니다. 이전 APK와 소스 기준본은 보존했습니다. 실제 사진의 시각적 화질은 검사하지 않았습니다.

## RAW 렌즈 근거

메타데이터 전용 탐색은 촬영 0회, RAW 요청 대상 없음, 픽셀 읽기 없이 통과했습니다. `output/photon-v0.7.5/photon-raw-lens-capabilities.json`에는 공개·물리 카메라 메타데이터와 요청 줌별 미리보기 결과 30개가 있습니다. 논리 카메라 0에 RAW 스트림을 설정하면 0.6/1/3/5배 미리보기 요청 모두 물리 카메라 5를 보고했습니다. 따라서 논리 줌만 추가해서는 이 기기의 자동 광학 전환을 구현할 수 없습니다.

후면 센서 4개 모두 물리 RAW 출력을 제공합니다. ID 2/5/7은 4080x3060, ID 6은 4000x3000이며 다중 해상도 RAW는 제공하지 않습니다. 광학 비율은 초점거리/센서 폭을 논리 카메라의 기준 광학계에 상대적으로 계산합니다. ID나 홍보용 배율을 하드코딩하지 않습니다. 사용자가 잠금을 해제한 뒤 무촬영 세션 검사를 통과했습니다. 기본 1배 → 0.6배 → 1배 → 2.7배 → 5.1배 → 수동 전면 → AUTO 복귀가 모두 촬영 준비 상태에 도달했고, 공개 카메라의 열기·닫기·다시 열기도 통과했습니다.

사용자가 직접 촬영한 5.061배 RAW3는 성공했습니다. 세 4080x3060 프레임 모두 물리 센서 7, 초점거리 18.6mm, 노출 8,333,700ns, ISO699를 보고했습니다. 획득 787ms, 다음 셔터 790ms, 합성 331ms, 쓰기 155ms, 총 1,289ms입니다. 합성이 2개 프레임을 채택해 4,332,678픽셀을 바꿨습니다. 합성 DNG 정확히 1개만 공개 저장했고 원본은 공개 저장하지 않았습니다. 헤더 검사에서 크기·방향 6·24,999,584바이트·저장 완료를 확인했습니다. 픽셀 검사나 내보내기는 없었습니다.

미리보기와 RAW는 같은 물리 소스를 사용하고 연속 촬영 중 변경을 막으며 해당 소스의 촬영 메타데이터·특성을 사용합니다. 광학 단계 전환을 DNG 픽셀의 연속 디지털 자르기로 설명하면 안 됩니다.

## HDR 후보 근거

0.7.4는 실제 노출쌍 1회의 다음 셔터 목표(1,180ms)를 충족했지만 교정 전에 거친 정렬을 거부했습니다. 수정 탐색은 기존 모호성 구간 안에서 분리된 후보를 최대 4개 보존하고 공통 원본 해상도 기준점으로 비교하며 최종 검증 조건을 유지합니다. 다섯 번째 유력 후보나 해소되지 않은 경계 가설이 있으면 불확실성을 숨기지 않고 거부합니다. 호스트 회귀 입력은 거친 안내 영상은 모호하지만 원본 세부가 고유한 경우를 다룹니다. 같은 신규 입력이 보존한 0.7.4 커널에서는 예상대로 실패했습니다.

## 처리 시간

AUTO 기록은 메타데이터, 두 번의 해독, HDR, 텍스처, JPEG 인코딩, 출력 메타데이터, 공개 저장을 따로 측정합니다. 커널 시간만으로 촬영·저장 전체 시간을 주장하지 않습니다.

제한된 화면 밖 GPU TextureGuard 실험은 합성 4080x3060 입력과 소형·경계·무작위·알파 입력 32개에서 픽셀·변경 개수 완전 일치를 통과했고 입력을 보존했습니다. 변경이 많은 입력은 CPU 제자리 처리 363/361/359ms, GPU 첫 호출 239ms, 후속 114/114ms였습니다. GPU 시간은 초기화·업로드·실행·읽기·정리를 포함합니다. 추가 전체 해상도 입력도 완전 일치했습니다. 변화 없는 평탄 입력은 CPU330ms/GPU 후속115ms, 변경 144픽셀의 다양한 경계 입력은 CPU177ms/GPU 후속100ms였습니다. 첫 호출은 각각 212/112ms이며 두 번째 입력은 프로세스·드라이버가 이미 준비됐을 수 있습니다. 이 값은 표본이며 보편적인 상한이 아닙니다.

AUTO는 8MP 이상 텍스처 처리에 GLES를 선택합니다. 작은 영상은 CPU를 사용하며 GPU 실패 시 입력을 보존하고 CPU로 대체합니다. 알고리즘과 최종 JPEG 품질은 유지했습니다. 상주 GPU 작업자·서비스·학습 모델·NPU 백엔드는 없으며 NPU 가속을 주장하지 않습니다.

## 검증

- 전체 디버그·릴리스 빌드, JVM 136회, 네이티브 4/4, lint 통과: 오류 0개, 기존 경고 13개, 제안 1개. 추가된 접근성 경고는 이름 있는 미리보기 뷰와 performClick으로 수정했습니다.
- 기기 HDR·저장·미리보기 회귀 10/10 통과.
- 잠금 해제 뒤 RAW 무촬영 세션 2/2 통과. 잠긴 화면에서 처음 시도한 광학 미리보기는 시간 초과했고 실패 로그를 보존했습니다.
- 선택적 GPU 일치·벤치마크 1/1 통과, 상태 `parity_passed`.
- CPU 경로 합성 HDR+텍스처 전체 저장 771ms: HDR159, 텍스처187, 두 해독162, JPEG 인코딩180, 메타데이터·공개 저장74ms. 실제 셔터 시간이나 화질이 아닙니다.
- 사용자 AUTO 촬영: 다음 셔터 1,070ms, JPEG 1개, 텍스처 변경 153개. 기준 획득이 늦어 짧은 HDR 노출을 생략했으므로 실제 HDR 합성 성공은 아닙니다. 메타데이터 검사는 통과했습니다. 이 결과와 RAW 결과 모두 모든 장면에서 1.2초를 보장하지 않습니다.
- 최종 통합 기기 12/12: HDR3, 저장5, 일반 미리보기2, RAW 세션2. 큰 저장 테스트는 실제 `gpu_gles31` 선택, 작은 영상은 CPU 대체를 요구했습니다. 전체 합성 HDR+텍스처 저장은 743ms(HDR157, 최초 GPU 설정 포함 텍스처172, 해독159, JPEG177, 메타데이터·공개 저장66ms)였습니다. 이전 CPU 실행 771ms와는 단일 실행 편차가 있어 안정적인 전체 개선 비율을 주장하지 않습니다.
- GPU 일치·변경 적은 입력 벤치마크 2/2, 실제 RAW/JPEG 메타데이터 검사 2/2는 별도로 통과했습니다.

## 남은 한계

최신 실제 HDR 시도는 두 번째 노출을 생략했습니다. 실제 HDR 합성 성공을 주장하지 않습니다. 당시 GPU는 AUTO TextureGuard에만 사용하며 RAW 합성·HDR 정렬은 CPU입니다. 확인된 망원 작업의 RAW 합성은 331ms였고 NPU는 사용하지 않습니다. 최종 GPU 통합은 합성 영상으로 검증했고 그 전 사용자 AUTO 촬영은 CPU였습니다. 카메라 콜백·초점 수렴·가득 찬 처리 대기열은 다음 셔터 목표를 넘길 수 있습니다. RAW 광학 전환은 세션을 재연결하는 불연속 단계이며 각 단계에서 전체 센서 DNG를 출력합니다.
