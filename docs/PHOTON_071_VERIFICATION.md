# PHOTON 0.7.1 수정 및 검증

2026-10-23. 다음 촬영까지의 지연과 RAW 미리보기 방향·화면 비율을 수정한 기록입니다.

## 수정 배경

0.7의 실제 AUTO HDR+텍스처 촬영에서 다음 셔터까지 2,933/2,223ms가 걸려 사용자의 1,200ms 목표를 넘었습니다. `exposure_settle_exceeded_hdr_budget`는 짧은 노출을 촬영하지 않았다는 뜻입니다. 합성 영상의 HDR 합성 49ms, 전체 처리·저장 664ms는 느린 노출 보정 대기와 별개입니다. 당시 근거는 기존 출력 폴더에 보존했습니다.

0.7.1은 현재 측광된 센서 노출·ISO, 고정된 초점·AWB, 수동 AE를 사용해 기준 노출과 1/4 노출을 요청한 뒤 이전 요청 설정을 복원합니다. 실제 카메라 콜백을 기다리며 시간 초과를 준비 완료로 취급하지 않습니다. 결과의 최신성·지원 기능·수렴 상태가 부족하면 HDR을 거부하고 기준 영상을 보존합니다.

## RAW 미리보기 수정

TextureView가 이미 처리하는 센서 회전·전면 반전을 다시 적용하고 회전 전 치수로 축별 확대하던 문제가 있었습니다. 추가 행렬은 이제 뷰의 불균일한 늘어남을 보정하고 디스플레이 회전만 적용한 뒤 같은 배율로 중앙 자릅니다. 화면 수명에 묶인 디스플레이 리스너가 180도 회전도 처리합니다.

센서 90도, 스트림 1920x1080, 세로 뷰 1080x1920, 디스플레이 회전 0인 경우 올바른 추가 변환은 항등입니다. 이전 행렬은 90도 회전과 불균일 확대를 중복 적용했습니다. 신규 테스트는 이 경우와 정사각형·직교·중앙 정렬·영역 채움을 포함한 128개 기하 조합을 확인합니다. DNG 방향과 RAW 픽셀은 변경하지 않았습니다.

근거: [Android 카메라 미리보기](https://developer.android.com/media/camera/camera2/camera-preview), [OutputConfiguration 반전](https://developer.android.com/reference/android/hardware/camera2/params/OutputConfiguration#setMirrorMode(int)).

## 검증 결과

`output/photon-v0.7.1/quality-gates-final.log`에서 Spotless, 디버그·릴리스 APK, Android 테스트 APK와 **JVM 테스트 실행 134회**가 통과했습니다. 진단 모듈의 디버그·릴리스 중복을 제외하면 130개이며, 신규 미리보기 4개/기하 조합 128개를 포함합니다. 디버그·릴리스 lint는 오류 0개, 기존 의존성·대상 버전 경고 13개, 기본형 상태 할당 제안 1개입니다. 첫 컴파일에서 Kotlin 접근자 불일치를 발견해 명시적 `getCaptureRequestOptions()` 호출로 수정했고 최종 검증을 통과했습니다. 네이티브 알고리즘은 0.7의 호스트 검증 4/4 이후 변경하지 않았습니다.

휴대폰 AUTO 기능·미리보기·재개 및 RAW 미리보기는 **3/3 통과**했고 사진은 촬영하지 않았습니다(`device-preview.log`). 설치된 디버그 APK와 로컬 APK의 SHA-256은 같습니다.

`1d43e6c752418c18ef2d761bf958bebf26d6da8789168c7cafa4be6ad12609c0`

사용자는 RAW 미리보기 축·비율이 정상이라고 확인했습니다.

사용자가 직접 촬영한 HDR+텍스처 작업 1회는 다음 셔터까지 **1,023ms**, 최종 저장까지 1,488ms였습니다. 4080x3060 JPEG 1개, 방향 6, 4,211,757바이트, MediaStore pending=0을 확인했고 메타데이터 전용 `PhotonAutoSavedTest`도 1/1 통과했습니다. 다만 **HDR 성공은 아닙니다**. `baseline_exceeded_hdr_budget`로 두 번째 프레임을 생략했습니다. 단계별 시간은 설정 450ms, 기준 촬영 324ms, 짧은 노출 0ms, 복원 247ms입니다. 선택된 기준 영상은 텍스처 처리로 12,796픽셀이 바뀌었습니다. 다음 단계는 제한 시간 내 두 노출을 모두 확보하는 것이며, 이 단일 프레임 결과만으로는 부족합니다.

실제 사진 자동 촬영이나 메타데이터 검사기의 픽셀 해독은 없었습니다. 입력·이전 APK는 `output/photon-v0.7.1/baseline`과 이전 출력 폴더에 보존했습니다. 테스트는 앱 소유 합성 결과만 삭제하며 실제 사진 픽셀은 검사하지 않았습니다. 이 출력 폴더는 로컬 검증 자료이며 공개 저장소에 포함되는 자료를 뜻하지 않습니다.
