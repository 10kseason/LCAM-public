# PHOTON 0.15.0 RAW HDR과 연속 줌

로컬 개발 후보, versionCode21입니다. 별도 RAW AUTO 실험과 후면 RAW 구도 조작을 확장했습니다. 당시 일반 AUTO 시작·처리와 SER Night는 독립 상태로 유지했습니다.

## 동작과 선택 이유

- RAW AUTO HDR은 기본 ON입니다. 기준 노출을 먼저 찍고 같은 ISO에서 셔터 시간 1/4·4배를 요청합니다. 긴 노출은 80ms 이하입니다. 1.8배 이상 분리가 안 되거나 물리 수동 제어가 없으면 기준 1장으로 대체합니다. ISO 증가를 추가 광량으로 계산하지 않습니다.
- 실제 노출 순서·요청/실제 시간 일치·동일 ISO·잠긴 AE·안정된 초점/WB/CCM/잔여 음영·고유 타임스탬프·올바른 노이즈 프로파일을 요구합니다.
- `NativeRawHdr`는 ±12 RAW 픽셀 안에서 짝수 단계로 CFA 셀을 정렬합니다. 모호하거나 과도한 이동·탐색 경계 정렬은 거부합니다. 셀 공통 신뢰도가 이웃과 노이즈 근거를 확인해 포화·움직임을 거부하므로 채널별 경계를 줄입니다.
- 짧은 노출을 하이라이트 기준으로 삼습니다. 채택한 기준·긴 프레임은 제한된 역분산 가중치를 사용하고 짧은 기준의 영향은 최소 20%입니다. JPEG 현상 전용 정규화 16비트 RAW를 출력해 원본 DN보다 작은 암부 정보를 보존합니다. 새로운 DNG 인코딩이나 날아간 세부 복원 주장이 아닙니다.
- 유효한 국소 합성이 없거나 렌더 게인을 지원하지 않으면 측광 기준 JPEG를 선택합니다. 자연 렌더러는 물리 색·음영 뒤 제한된 암부 상승과 공통 RGB 하이라이트 곡선을 적용합니다. JPEG97 인코딩은 한 번이며 렌더 실패는 기준 DNG 1개로 대체합니다.
- RAW AUTO와 후면 자동 렌즈 RAW에 핀치·로그 슬라이더·빠른 줌 버튼을 제공합니다. 실제 물리 렌즈와 디지털 자르기를 합쳐 최대 8배입니다. 최소는 0.6배 이상이면서 장치가 제공하는 광학 화각 안에서 정합니다. 상향 4% 완충 구간으로 렌즈 반복 전환을 줄입니다. 센서 전환에는 짧은 Camera2 재열기가 필요하며 끊김 없는 ISP 교차 전환은 아닙니다.
- JPEG는 확대 보간 없이 자릅니다. DNG는 전체 센서 픽셀·CFA·교정을 유지하고 실제 ActiveArea 기준 `DefaultCropOrigin/DefaultCropSize`로 구도를 설명합니다. 일부 RAW 편집기는 이 값을 무시해 전체 센서를 보여줄 수 있습니다. 광학·디지털 배율·픽셀 자르기를 기록하며 미리보기는 4:3 안에서 디지털 자르기·터치 좌표를 맞춥니다.
- 비공개 기준 DNG는 구도 수정 중에도 바꾸지 않습니다. 별도로 생성한 임시 DNG를 검증한 뒤 메타데이터를 고치며 쓰기 실패 시 원본을 복구용으로 보존합니다. JPEG/DNG는 하나의 UUID 결과만 공개합니다. DNG 영속 저장 전 프로세스 사망은 여전히 한계입니다.

## 실제 단일 프레임 기준 사진

사용자가 설치된 0.14.0의 실제 시험 촬영 1회를 승인했습니다. JPEG4080×3060, 물리 센서5, ISO451, 8.3337ms, −0.7EV, 인코딩 1회·결과 1개입니다. 기록은 준비 501ms, 처리·저장 1,352ms(렌더989ms)이며 단일 표본입니다. 실내 책상의 케이블·어두운 장치 표면·인쇄물을 촬영했고 암부 색 노이즈가 보였습니다. 하늘·거리의 자연스러움을 증명하지 않습니다. 사진은 휴대폰에 유지하고 앱 소유의 해당 결과만 로컬로 복사해 검토했습니다. 근거는 비공개 로컬 `output/photon-v0.15.0/real-baseline/receipt.json`, `raw-auto-baseline.jpg`입니다.

## 검증 범위

최초 전체 네이티브8·JVM·Spotless·디버그/릴리스 lint·모든 APK 검증은 통과했습니다. 후속 실패 경로 검토에서 부분 연속 촬영 보존·렌더 게인 경계를 수정했으므로 아래 최종 기록을 기준으로 봅니다.

신규 호스트 검사는 정지·이동 암부 노이즈, 포화 하늘, 움직이는 영역, 모호한 평탄 정렬, ROI, 잘못된 메타데이터, 입력 불변·결정성을 다룹니다. 합성 암부 MSE 비율은 0.0568/0.0562로 실제 카메라 화질 점수가 아닙니다. JVM은 노출쌍 경계·자르기·메타데이터, 두 TIFF 바이트 순서, 센서 데이터 불변, 잘못된 메타데이터 거부를 검사합니다. 기기는 JNI·자르기 해독·연속 광학/디지털 줌·상태 복원을 다루며 명시적으로 켜지 않으면 셔터를 누르지 않습니다.

`RawHdrCaptureDeviceTest`는 `realRawHdrCapture=1`이 아니면 생략합니다. 활성화하면 셔터 1회·노출 3개·공개 결과 1개를 만들고 해당 승인 촬영의 진단용 원본 DNG를 앱 내부에 보존합니다. 승인 없이 켜면 안 됩니다. 합성 공개 테스트 결과는 정확한 URI만 삭제합니다.

## 남은 화질 확인

실제 야외 하늘·건물·나무·사람은 사용자 판단이 필요합니다. 평행 이동만 정렬하므로 임의의 손 회전·시차·독립적 움직임을 보정할 수 없고 거부 영역에 더 노이즈 많은 짧은 기준이 남을 수 있습니다. 믿을 만한 센서 근거 아래의 매우 어두운 표본은 강하게 올리지 않습니다. 학습 노이즈 제거·실시간 최종 톤·하늘 분할·손실 없는 디지털 확대·일반 AUTO 교체는 주장하지 않습니다.

## 최종 검증 기록

- 앱 최종 통과: JVM188회(실패·생략0), 네이티브8, Spotless, 디버그·릴리스 lint 오류0/경고16/제안7, 디버그·릴리스·androidTest 빌드.
- 테스트 구동 수정 후 서로 다른 선택 기기 검사 **18개 통과**: HDR 합성/JNI3(4080×3060 포함), DNG 자르기1, RAW 줌/세션2, 시작/권한/탐색2, RAW Pro1, Night 미리보기1, RAW AUTO 렌더/공개 저장3, 기존 SER CPU/GPU4, 실제 HDR1. 전체 해상도 합성 HDR 커널1,557ms, 실제 장면의 거부 처리 포함453ms는 입력이 달라 전체 속도 보장이 아닙니다.
- DNG 검사는 AndroidX가 IFD0 자르기 태그를 제공한다고 잘못 가정했습니다. 독립 TIFF 검증으로 두 자르기 배열·전체 치수·모든 무관 바이트를 확인하도록 수정했습니다. UI는 Android CLI 도우미가 같은 UiAutomation 연결을 잡아 오래된 접근성 상태를 보았습니다. 실제 스와이프는 작동했습니다. 해당 도우미만 종료하고 앱 검사를 단독 실행해 2개 UI가 통과했습니다. 두 UI 구동기를 동시에 쓰면 안 됩니다.
- 사용자가 0.15 설치·무촬영 검사·추가 HDR 셔터 **1회**를 승인했습니다. 설치 앱과 묶음 디버그 APK 해시가 일치합니다. 테스트 APK 변경은 구동 코드만 수정했습니다.
- 실제 HDR 통과: 물리5, 원본4080×3060, ISO382, 16.6674/4.16685/66.6696ms, 실제 비율1/.25/4. 세 장 모두 이동0으로 정렬됐고 8,116,972픽셀 합성·1,084,821셀 거부입니다. `hdrApplied=true`, 최신 미리보기 복원, JPEG 인코딩1회·공개 결과1개. 1.4배 자르기 `[582,438,3496,2622]`로 2914×2184 JPEG를 만들었습니다. 비공개 원본 DNG 헤더로 전체 센서 크기·세 노출을 독립 확인했고 원본은 모두 보존했습니다.
- 실제 획득1,546ms, 다음 준비1,744ms, 처리·저장1,865ms(HDR453/렌더1,036ms). 진단 DNG까지 보존한 단일 계측 표본이며 **1,200ms 준비 목표를 초과**했습니다. 처리량 목표 충족이나 촬영→파일 전체 상한을 주장하지 않습니다.
- 시각적 검토는 실내 책상·케이블·인쇄물이며 구도는 맞지만 암부 색 노이즈가 남습니다. 야외 하늘·거리 사진이나 사용자의 자연스러움 수용은 아직 없습니다. 기준·HDR 사진은 줌·노출이 달라 통제된 화질 A/B 비교가 아닙니다.

로컬 근거: `device-real-hdr.log`, `real-hdr/receipt.json`, `real-hdr/raw-hdr-1.4x.jpg`, `real-hdr/source-{0,1,2}.dng`, `real-hdr/dng-header-validation.json`, `final-gate.log`, `device-main.log`, `device-repair.log`, `device-ui-isolated.log`, `device-regression.log`. 실패한 구동 로그도 보존하며 후속 범위별 통과와 구분합니다. 사진·DNG는 공개 문서 첨부를 뜻하지 않습니다.
