# PHOTON 0.7.3 HDR 응답 교정과 촬영 완료 처리

2026-10-23. 실제 두 노출을 확보했지만 1,297ms와 `exposure_mismatch`를 기록한 0.7.2의 후속 작업입니다. 이미 확인한 RAW 단일 결과 저장과 미리보기는 변경하지 않았습니다.

## 카메라 요청 순서

ImageCapture 전용 Camera2 콜백은 메타데이터만 관찰합니다. 바인딩별 관찰자가 시작·완료 요청의 동일성, 프레임 번호, STILL_CAPTURE 의도, AE OFF, 요청 노출·ISO를 대조합니다. 짧은 프레임은 같은 세션에서 확인한 기준 프레임 뒤에 와야 합니다. 이 조건을 충족하면 JPEG 인코딩·쓰기가 진행되는 동안 이전 요청 옵션을 복원할 수 있습니다. JPEG 완료와 복원이 모두 끝나야 카메라 잠금을 풉니다.

관찰자는 Camera2 세션에 촬영을 요청하거나 세션을 닫지 않습니다. 메타데이터가 없으면 JPEG 완료 후 복원하는 경로로 돌아갑니다. 실패·취소 경로에서도 대기 중인 설정 Future를 모두 정리합니다. `shortSensorCompleteOffset`, `restoreStartOffset`, `shortFileReadyOffset`으로 실제 겹침을 확인할 수 있습니다. 단계 시간이 겹칠 수 있으므로 직렬 작업처럼 합산하면 안 됩니다. `shutterReadyMs`가 실제 다음 촬영 허용 시간입니다.

## 밝기 관계 거부 개선

0.7.2의 실제 EXIF 비율은 4.02521이었지만 역 sRGB 값이 가정한 선형 배율과 맞지 않아 두 영상을 거부했습니다. 수정된 네이티브 알고리즘은 그 밝기 가정 없이 기하 대응을 찾고, 포화되지 않은 대응점에서 제한된 단조 응답을 추정한 뒤 독립 표본으로 검증합니다. 모호성·역방향 정렬·움직임·하이라이트 한정·변경량 제한은 유지합니다. 새 진단값은 집계 개수와 오차만 담습니다. 텍스처 생성이나 임의의 임계값 완화로 성공을 대신하지 않습니다.

## 검증 결과

빌드·디버그/릴리스 APK·서식·JVM 134회·lint가 통과했습니다(`quality-gates-final.log`). lint는 오류 0개, 의존성·대상 경고 13개, 기본형 상태 제안 1개입니다. MSVC 네이티브 4/4가 통과했고 비선형 응답과 이동, 독립 검증 표본의 불일치, 움직임 거부, 근거 없는 외삽 거부, 중간톤 보존을 다룹니다. 첫 통합 검증은 빌드 중 테스트 입력이 수정되어 실패했습니다. 최종 입력을 고정한 뒤 운영 코드의 검증 조건을 바꾸지 않고 통과했으며 실패 로그도 보존했습니다.

기기 검사는 **10/10 통과**했습니다(`device-tests.log`). 비선형 JPEG 응답을 포함한 네이티브 HDR, 단일 결과 저장·복구, 노출된 모든 렌즈의 미리보기·재개를 검사했습니다. 실제 셔터 자동 조작은 없었습니다.

휴대폰의 합성 4080x3060 입력 결과:

- 네이티브 HDR **65ms**, 변경 168,448픽셀, 합성 채택, 중간톤·짧은 입력 보존.
- JPEG 두 장 해독+HDR+텍스처+최종 인코딩·저장 **680ms**, 최종 JPEG 정확히 1개. HDR 64ms, 변경 175,488픽셀, 독립 교정 검증 표본 일치율 99.65%, RMSE 0.01462.
- 개발 환경의 단일 합성 처리 측정이며 카메라 촬영은 제외합니다. 실제 화질이나 다음 셔터 목표를 증명하지 않습니다.

## 실제 촬영 후속 확인

사용자 촬영 3회의 기록을 사진 픽셀 없이 읽었습니다. 2회는 실제 노출쌍(EXIF 비율 4.02521)을 확보했지만 둘 다 교정 전에 정렬에서 거부됐습니다. 비용은 0.40634/0.40932, 분리도는 0.00588/0.00089였습니다. 이는 현재 탐색 범위에서 믿을 만한 대응점을 찾지 못했다는 근거이며, 실제 이동량이나 원인을 증명하지는 않습니다.

다음 셔터 **1,212/1,222ms**는 여전히 목표를 초과했습니다. 조기 복원은 실행됐지만 JPEG 완료와 겹친 시간은 33/26ms뿐입니다. 첫 촬영은 1,097ms였지만 허용 예산 때문에 짧은 노출을 생략했으므로 HDR 성공이 아닙니다.

세 기록 모두 완료된 4080x3060 JPEG 1개, 방향 6, 올바른 소유권·EXIF를 확인했습니다. 선택적으로 실행하는 메타데이터 검사가 세 기록 URI에 대해 통과했습니다(`real-metadata-readback.log`). 이전 RAW의 587ms·합성 DNG 1개 결과는 별도 근거입니다.

완전한 HDR 수용 조건은 아직 충족하지 못했습니다. 다음 후보는 범위가 제한된 더 넓은 다중 해상도 탐색과 요청 안전성을 지키는 조기 복원을 검토합니다. 성공을 만들기 위해 검증 조건을 완화하지 않습니다.
