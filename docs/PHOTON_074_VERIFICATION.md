# PHOTON 0.7.4 HDR 정렬 범위와 요청 순서 개선

2026-10-23. 보존된 0.7.3 후보는 실제 노출쌍 2회를 촬영했지만 정렬에 실패했고 다음 셔터까지 1,212/1,222ms가 걸렸습니다. 메타데이터 검사로 촬영당 최종 JPEG 1개를 확인했습니다. 당시 시간과 실패는 `PHOTON_073_VERIFICATION.md`에 남아 있습니다.

## 변경 범위

12MP 영상의 더 큰 평행 이동을 처리하도록 범위가 제한된 다중 해상도 정렬 안내 영상을 사용합니다. 축소 안내 영상은 정렬에만 쓰며 최종 처리와 JPEG 크기는 원래 해상도를 유지합니다. 모호성·역방향 대응·밝기 응답 교정·국소 움직임 검증도 유지합니다. 실패 기록만으로 실제 카메라 이동량을 알 수는 없습니다. 탐색 확대는 특정 한계를 검증하는 수정이며 장면 원인의 확정은 아닙니다.

`SYNC_MAX_LATENCY_PER_FRAME_CONTROL`을 보고하는 카메라에 한해, 정확히 일치하는 짧은 정지영상 요청이 시작되면 반복 요청 옵션을 복원합니다. 해당 요청은 불변이고 이 기능은 프레임별 제어 변경의 원자성을 보장하므로 후속 반복 요청이 이미 제출된 촬영 설정을 바꾸지 않습니다. 나머지 카메라는 완료 콜백에 따른 복원을 유지합니다. 시작 콜백이나 복원 대기열 등록 자체는 준비 완료가 아닙니다. 짧은 JPEG와 성공한 복원이 모두 완료되어야 합니다. 콜백 근거가 없으면 직렬 경로를 유지합니다.

공식 계약: [프레임별 제어](https://developer.android.com/reference/android/hardware/camera2/CameraMetadata#SYNC_MAX_LATENCY_PER_FRAME_CONTROL). `onCaptureStarted`는 노출 시작이며 센서 프레임이나 JPEG 완료가 아닙니다.

## 검증

빌드·서식·디버그/릴리스 lint(오류 0개), JVM 134회, 네이티브 4/4가 통과했습니다. 네이티브 검사는 40/81/100픽셀 이동, 비선형 응답, 홀수 크기, 탐색 경계·범위 밖·반복 무늬 거부와 기존 보존 조건을 포함합니다. 휴대폰 합성 저장·HDR·렌즈 미리보기는 **10/10 통과**했습니다(`device-tests.log`).

합성 4080x3060 영상의 휴대폰 네이티브 HDR은 **157ms**, 전체 해독·HDR·텍스처·인코딩·저장은 **766ms**였고 최종 영상 1개를 만들었습니다. 넓은 탐색 때문에 0.7.3보다 계산량이 늘었습니다. 최종 해상도를 낮추거나 보존 대상 합성 결과를 바꾸지는 않았습니다. 카메라 획득을 제외한 수치이므로 실제 화질이나 다음 셔터 시간을 증명하지 않습니다.

## 실제 촬영 후속 확인

실제 노출쌍 1회(EXIF 비율 4.02521)의 다음 셔터는 **1,180ms**였습니다. 시작 콜백에 따른 복원이 작동했습니다. 짧은 노출 시작 861ms, 설정 정리·복원 시작 962ms, 센서 완료 994ms, JPEG 완료 1,035ms, 촬영·복원 완료 1,177ms입니다. 처음으로 측정된 1,200ms 이내 노출쌍이며 모든 조건의 상한은 아닙니다.

HDR은 여전히 거친 정렬 가설을 거부했습니다. 비용 0.29192, 분리도 0.03930, 기준점 355개, 마지막 후보 (0,-8)입니다. 교정에 도달하지 않았고 HDR 변경 픽셀도 없습니다. 이는 시간 개선이며 HDR 합성 성공이 아닙니다. 다른 신규 기록은 노출 미수렴 대체 905ms, 짧은 프레임 예산 초과 대체 972ms, HDR OFF 871ms입니다.

4개 기록마다 완료된 JPEG 1개가 저장됐고 선택적 메타데이터 검사가 통과했습니다. 실제 사진 픽셀 검사나 실제 셔터 자동 조작은 없었습니다. 완전한 HDR 수용 조건은 아직 충족하지 못했습니다. 기록과 APK는 당시 로컬 출력 자료입니다.
