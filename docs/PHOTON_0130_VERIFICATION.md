# PHOTON 0.13.0 로컬 후보 — AUTO/RAW 사용 흐름과 RAW Pro

2026-10-24. 요청 순서는 RAW 저장 중 종료 보호, AUTO/RAW 직접 전환, 터치 초점·노출, Pro 제어였습니다. 당시 로컬 개발 후보이며 공개 릴리스가 아닙니다.

## 동작과 선택 이유

- AUTO 상단에 RAW, RAW에 AUTO 직접 버튼을 둡니다. 새 시작은 AUTO를 유지합니다. RAW 셔터·재연결은 설정 스크롤 밖에 고정합니다.
- AUTO의 닫기·뒤로는 AUTO/RAW/Night의 진행 중 획득·처리를 모두 확인합니다. 화면을 떠난 RAW 작업도 포함합니다. 대기 작업이 있으면 실시간 상태 대화상자를 열고 종료를 막습니다. 완료되더라도 자동 종료하지 않으며 사용자가 저장·실패 메시지를 보고 명시적으로 닫거나 촬영으로 돌아갑니다. 이벤트 시점에도 최신 작업 상태를 다시 읽습니다.
- 이는 앱 안에서의 의도적 종료를 보호합니다. Android 강제 종료·작업 제거·프로세스 사망·전원 상실·백그라운드나 권한 변경으로 중단된 획득의 복구를 보장하지 않습니다. 서비스·시작 등록·상주 에이전트·권한은 추가하지 않습니다.
- RAW 누름·길게 누름은 지원 시 센서 좌표 AF/AE 측광을 요청합니다. 핀치가 초점 누름으로 바뀌지 않습니다. 표시는 Camera2의 성공·실패이며 광학 선명도가 아닙니다. 터치 AF 렌즈만 수동 초점을 해제합니다. 수동 노출에서는 AE 영역이 효과 없고, 측광만 지원하는 렌즈는 초점 성공을 가장하지 않고 설명합니다.
- **초점·Pro**에서 EV, 수동 ISO+셔터, 수동 초점, WB 사전 설정을 제공합니다. 미지원 제어는 숨기거나 끕니다. 물리 센서는 명시적인 물리 요청 키 지원이 필요합니다. 스크롤 Pro 시트는 완전히 펼쳐 열어 제어 추가 뒤 재진입해도 수동 노출 스위치가 가려지지 않게 합니다.
- 수동 노출은 마지막 관측 프레임의 ISO·시간 쌍으로 시작합니다. 셔터 범위는 센서·프레임 시간 한계와 제품의 1초 상한을 교차 적용합니다. 장노출이나 모든 장면에서 1.2초 준비를 보장하지 않습니다. 수동 노출 중 EV는 끄며 초점은 디옵터(0=무한대)로 표시합니다.
- WB는 장치가 제공하는 AUTO·주광·흐림 등의 모드만 사용합니다. 임의 Kelvin 교정이나 일반 RGB 게인 곡선은 넣지 않습니다. DNG는 실제 메타데이터를 유지하고 외부 현상기는 다르게 해석할 수 있습니다. Bayer 픽셀에 JPEG 필터를 굽는 기능이 아닙니다.
- 같은 프로세스의 같은 렌즈 재열기·Activity 재생성에서는 제어를 유지합니다. 렌즈 변경은 자동으로 초기화하고 지원·범위를 다시 확인합니다. 프로세스 사망 후 제어는 보존하지 않으며 기존 RAW 합성 선택의 별도 저장은 유지합니다.

## 제어 정확성과 경계

기존 카메라 Handler에서 제어를 요청합니다. 슬라이더 변경은 100ms 모아 이전 요청을 대체하며 세대·요청 검사가 다른 렌즈의 콜백 반영을 막습니다. 제어 갱신·실패 중에는 촬영을 막습니다. 태그가 맞는 최신 미리보기 결과가 AE/AF/WB/EV 모드와 센서 값을 확인해야 합니다. 허용 오차는 노출 max(50us,5%), ISO max(1,10%), 초점 0.1D입니다. 시간 초과는 실패로 보고하고 초기화·재시도를 요구하며 검증되지 않은 설정으로 촬영하지 않습니다.

획득 준비는 수동 AE·고정 WB에 자동 3A 수렴 대기를 잘못 적용하지 않습니다. 같은 제어를 잠긴 연속 촬영과 복원 미리보기에 적용합니다. Night의 사용자 제어는 null이며 새 물리 키는 RAW 제어에만 복사해 기존 Night 정책을 보존합니다. 네이티브 합성·색 커널은 유지합니다.

RAW 기록에는 기존 ISO·노출 외에 요청 제어와 프레임 보고 AE/AF/WB/EV/초점을 선택적으로 남깁니다. 앱 비공개 진단 메타데이터이며 공개 DNG 형식은 그대로입니다. 입력 RAW는 메모리에 존재하고 최종 DNG 1개 또는 기준 DNG 대체 정책을 유지합니다.

측광 좌표는 센서·화면 회전, 전면 반전, 중앙 채움 자르기, 스트림 비율, 센서 자르기·활성 배열을 반영합니다. 순수 기하 검사만으로 피사체 초점 정확성이나 모든 렌즈의 모서리 동작을 증명하지 않습니다. 공식 의미: [Camera2 CaptureRequest](https://developer.android.com/reference/android/hardware/camera2/CaptureRequest).

## 검증

- 최초 Kotlin 컴파일 통과, 첫 서식 검사에서 긴 UI 표현식을 발견해 수정했습니다.
- 첫 전체 빌드·서식·JVM·네이티브·디버그/릴리스 lint·세 APK 검증 통과.
- 최신 종료 상태 확인, 기능별 터치 안내, 렌즈별 노출 범위 표시 후 최종 검증: JVM 165회(실패·오류·생략 0), 네이티브 7개, Spotless, 디버그·릴리스 lint, 세 APK 통과. 각 lint는 오류 0, 경고 16, 제안 3이며 경고가 없는 빌드는 아닙니다.
- 자동 검토가 이전 승인을 0.12.0에 한정한 뒤 사용자가 0.13.0 설치·검사를 명시적으로 승인했습니다. 데이터 보존 상태로 앱·테스트 APK를 설치했습니다.
- 초기 기기 검사: 시작·권한·종료·RAW Pro 4개와 RAW/Night/히스토그램 회귀 6개 통과. 미리보기·메타데이터·합성 상태만 사용했습니다.
- 확장 UI 검사에서 재생성 후 덜 펼쳐진 Pro 시트가 수동 노출을 가리는 문제를 발견했습니다. 완전 펼침으로 수정해 ON/OFF, 같은 렌즈 재생성 보존, 직접 전환·뒤로가 통과했습니다.
- 중간 RAW 입력 검사에서 연결 해제·닫힘 및 4초 시간 초과 1회가 있었습니다. Activity의 View만 바꿔 기존 Compose 카메라가 살아 있던 문제는 구성을 교체하고 UI 해제를 기다린 뒤 AUTO를 명시적으로 닫아 수정했습니다. 시간 초과는 렌즈·단계·실제 값 진단 추가 뒤 재현되지 않았으나 원인을 확정하지 못해 로그를 보존했습니다. 통과를 위해 운영 시간 초과나 허용 오차를 완화하지 않았습니다. 최종 개별 RAW 제어 검사 통과.
- 최종 통합 **10개 통과**, 43.855초(`device-final-suite.log`). Pro UI·재생성, 종료 보호, RAW 광학 렌즈 4개의 제어, RAW/Night 재열기, AUTO 히스토그램 포함, 생략 없음. 최종 결과는 중간 실패를 숨기지 않고 이후의 통과 상태를 기록합니다.
- RAW 물리 렌즈 4개에서 10ms/ISO400/백열등 WB/수동 무한대 초점 허용. 실제 ISO는 398/398/400/399, 노출 모두 정확히 10ms, WB 모드 2였습니다. 미리보기 기반 준비가 수동 AE/AF/WB를 유지했고 EV·자동 초기화도 통과했습니다. 중앙 AF는 3개 FOCUSED_LOCKED, 1개 NOT_FOCUSED_LOCKED였으며 이를 광학 선명도와 동일시하지 않습니다.
- 실제 셔터 자동 조작, 개인 사진 접근, 실시간 미리보기 화면 저장, 외부 업로드는 없었습니다.

## 남은 검사와 제외 범위

수동 RAW1/RAW3 실제 DNG 촬영·메타데이터·시각적 초점/WB, 실제 RAW 저장 중 모드 전환·종료, 디스크 부족·프로세스 종료·발열·가득 찬 대기열, 모서리 광학 좌표·전면·장면별 AF는 미검증입니다. 합성 UI 검사는 실제 파일시스템 부하 검사가 아닙니다. LUT·초점 피킹·일반 RAW→JPEG 현상·1초 초과 노출은 추가하지 않았습니다.
