# 0.16.1 코드 감사와 공개 준비 검증

2026-10-24 기준 개발 미리보기입니다. 0.16.0의 기본 RAW AUTO·공통 화면·확대 프리뷰 경계 수정을 유지하고, 공개 전 코드 검토에서 발견한 저장·노출 경계 문제를 보완했습니다.

## 검토 범위

작성한 Kotlin·C++·헤더·Python 코드 202개 파일 전체를 읽고 검토했습니다. 앱의 AUTO·RAW·RAW AUTO·야간 경로, 기반 모듈, 네이티브 처리, 합성 실험과 검사 코드를 포함합니다. 빌드 설정·매니페스트·리소스도 별도로 검토했습니다. 생성 코드, 의존성 내부 전체 소스, Android·제조사 HAL 구현은 이 전수 검토 범위에 포함하지 않습니다. 검토는 결함 부재의 증명이 아닙니다.

외부 5개 저장소의 1,083개 소스 파일과 별도 비교했습니다. 긴 토큰 일치 후보는 모두 패키지·import 선언으로 판별됐고, 선언 제외 본문 비교에서는 기준 이상의 일치 후보가 없었습니다. [비교 방법·결과·한계](SOURCE_PROVENANCE.md)와 재현 도구·메타데이터를 함께 제공합니다.

## 수정한 문제

| 영역 | 이전 문제 | 변경과 이유 |
| --- | --- | --- |
| RAW AUTO 노출 | 양수 EV 또는 -2 미만 EV에서 현상이 실패할 수 있고, 음수 EV는 현상에서 상쇄될 수 있었음 | 셔터 시 고정한 초기 하늘 보호 바이어스만 보정하고 사용자 EV는 촬영 밝기에 남김 |
| 복구 저널 | JSON 갱신 도중 종료되면 보존 원본을 찾지 못할 수 있었음 | AtomicFile로 저널을 갱신·복구하고, DNG를 임시 이름에 완전히 쓰고 동기화한 후 복구 이름으로 바꿈 |
| 야간 JPEG 복구 | JPEG 픽셀은 완전하지만 EXIF 기록이 끝나지 않은 파일을 복구할 수 있었음 | 메타데이터 기록과 동기화 이후에만 완료 표식을 기록. 표식 없는 작업은 기준 DNG 복구 우선 |
| 야간 복구 버튼 | 카메라가 준비되지 않으면 기존 저장 작업의 복구도 막힘 | 디스크 작업 복구를 카메라 준비 상태와 분리 |
| DNG 공개 결과 불명 | 저장 응답과 재조회가 모두 실패하면 유일한 결과 후보가 삭제될 수 있었음 | 결과 불명 후보는 보존하고 중복 대체 저장을 금지. 확인 실패 상태를 표시 |
| AUTO 완료 기록 | 앱이 배경으로 가서 다음 셔터 준비가 확인되지 않으면 저장 완료 기록이 누락될 수 있었음 | 사진 저장 완료를 먼저 기록하고 셔터 준비 지연은 미측정으로 남김. 실제 준비 시각이 오면 갱신 |

기기 검사에서는 기본 RAW AUTO와 AUTO 전용 검사 화면이 동시에 카메라를 열지 않도록 수명주기를 명시했습니다. JPEG 저장본 검사는 MIME 형식으로 DNG를 제외하고, 야간 저장본 버전 확인은 과거 버전 상수 대신 실제 앱 버전을 기준으로 했습니다. 기존 네이티브 GPU 수식 검사를 호스트 검사 목록에 연결했습니다.

| APK | 개발 서명 Debug, 서명 없는 Release, 검사 APK 빌드 통과 |

기기 검사에는 기본 시작·화면 전환·재생성, 세로·가로 확대 프리뷰 경계, 초점·EV, 히스토그램, 합성 HDR, DNG 크롭, 저널 중단과 원본 보존, JPEG 완료 표식, 단일 결과 공개가 포함됩니다. 첫 실행은 32개 중 히스토그램 재생성 검사 1개가 실패했습니다. 검사 전용 AUTO 화면을 정지 상태에서 구성한 뒤 재개하도록 수정하고 전체 32개를 다시 실행해 통과했습니다. 실패 기록을 삭제하거나 최초부터 통과한 것으로 취급하지 않습니다.

마지막 변경은 라이선스 원문 자산 추가입니다. 이후 APK를 다시 빌드하고 포맷·lint 및 APK 내 원문 일치를 확인했습니다. 카메라 코드는 32개 기기 검사 통과 때와 같습니다. 기존 lint 경고는 의존성·대상 SDK 갱신 안내와 일부 UI·API 스타일 항목이며 이번 작업에서 대규모 의존성 교체는 하지 않았습니다.

## 개인정보와 배포 경계

공개 소스와 APK에서 비밀키·개인 Windows 경로·실사 사진·기기 고유 ID·개인 백업 링크를 검사합니다. 커밋 작성자 주소도 GitHub 비공개 이메일 형식인지 확인합니다. 기기 시험은 새 실사 촬영 없이 수행하며 검사에서 만든 임시 사진만 정리합니다. 촬영 원본과 이전 릴리스는 공개 대상에서 제외하고 로컬에 보존합니다.

기존 비공개 저장소의 과거 커밋에서 개인 백업 폴더 링크 1건을 확인했습니다. 사용자 선택에 따라 기존 저장소는 비공개로 보존하고, 그 이력을 가져오지 않은 새 `LCAM-public` 저장소에 현재 소스를 공개합니다. 현재 문서에서는 링크를 제거했습니다. 공개 내보내기는 텍스트 줄바꿈을 Git 규칙에 맞추며, 비교 결과의 파일 해시는 그 공개 소스를 기준으로 다시 확인합니다.

개발 서명 키와 개인 인증서는 게시하지 않습니다. APK에는 표준 Android Debug 공개 인증서가 포함되며 비밀키가 아닙니다. 기술 문서와 릴리스 설명은 한국어로 정리하고, 외부 라이선스·저작권 고지 원문과 API·파일 식별자는 보존합니다.

## 남은 한계

새 야외 사진을 찍어 하늘·거리의 자연스러움과 움직임을 평가하지는 않았습니다. 32개 선별 검사가 모든 실촬영·GPU 품질 검사 전체를 실행했다는 뜻도 아닙니다. 메모리에만 남은 RAW의 강제 종료 복구, 모든 제조사 카메라 호환성, 발열·장시간 연속 촬영 품질은 보장하지 않습니다. 이 버전은 정식 배포 서명본이 아닌 개발 미리보기입니다.
