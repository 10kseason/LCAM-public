# PHOTON 0.16.0 RAW AUTO 기본 도구와 공통 카메라 화면

당시 게시하지 않은 로컬 후보의 기록입니다. 카메라 탐색·비율·도구를 바꾸며 네이티브 HDR·자연 톤·SER 렌더 알고리즘은 변경하지 않습니다.

## 동작과 선택 이유

- 카메라 권한이 있으면 새 시작은 RAW AUTO입니다. 사용 가능한 RAW AUTO 광학 후보가 없는 기기는 AUTO로 돌아가고 일시적인 연결 오류는 재시도를 유지합니다. OS 재생성은 현재 모드를 보존하며 권한 안내는 진단 페이지를 열지 않습니다.
- AUTO·RAW AUTO·RAW·Night가 어두운 색, 직접 모드 버튼, 원형 셔터, 최근 사진 위치, 세로·가로 배치를 공유합니다. RAW HDR·암부 강도·수동 Pro는 설정 시트로 옮깁니다. RAW/Night 뒤로는 AUTO로, 닫기는 기존 전체 처리 경로의 저장 대기 보호를 거칩니다.
- RAW 미리보기를 Compose와 네이티브 양쪽에서 자릅니다. FrameLayout이 변환된 TextureView를 자르고 크기 변경 때 명시적인 clip 경계를 갱신해 줌이 모드 버튼·셔터를 덮지 못하게 합니다. 초점 터치는 맞춰진 미리보기 안에 유지합니다.
- RAW AUTO/RAW에 4:3·16:9·21:9, EV, 격자, 수평계, 미리보기 히스토그램, 초점 해제, 앱 소유 최근 사진 보기를 추가합니다. 설정은 모드별 저장이며 RAW AUTO HDR·암부 강도도 저장합니다. Night는 기존 고정 1배·4:3 획득 경로를 유지합니다.
- 비율은 셔터 때 고정합니다. JPEG와 DNG 기본 자르기는 디지털 줌 뒤 같은 중앙·짝수 Bayer 셀 자르기를 사용합니다. DNG 전체 센서·교정 데이터는 보존하고 복구에는 저장된 비율·줌을 쓰며 예전 작업은 원본 비율로 해석합니다.
- 히스토그램은 활성화·재개 중인 현재 TextureView만 96x96, 최대 4Hz로 읽습니다. 버퍼는 재사용하고 중단 시 해제하며 픽셀은 저장하지 않습니다. 이 방식으로 미지원 가능성이 있는 Camera2 분석 스트림을 추가하지 않습니다. 이는 처리된 미리보기 밝기이며 최종 RAW AUTO 톤·센서 포화가 아닙니다. TextureView.getBitmap은 뷰의 setTransform 없이 레이어를 복사하므로 작은 비트맵에 정규화된 미리보기 변환을 명시적으로 적용합니다. 메모리 패턴의 합성 기기 회귀 검사로 줌 미적용·정상 1회·중복 적용을 구분합니다. 근거: [AOSP Readback](https://android.googlesource.com/platform/frameworks/base/+/ae82d1bf4313/libs/hwui/Readback.cpp)의 LayerDrawable::DrawLayer에 전달되는 useLayerTransform=false.
- 최근 사진은 RAW/RAW AUTO별로 분리한 크기 제한 앱 소유 기록만 읽습니다. JPEG/DNG에 맞는 MIME을 뷰어에 전달하며 갤러리 열거·광범위 미디어 권한을 추가하지 않습니다.

## 범위 경계

AUTO의 JPEG TextureGuard/DetailGuard는 이미 ISP 처리된 JPEG에 적용하는 기능이므로 RAW 자연 렌더러에 복사하면 별개 처리 단계가 중복됩니다. 이식하지 않고 RAW AUTO의 RAW HDR·자연 암부 제어를 유지합니다. 새 노이즈 제거·하늘/거리 화질·매끄러운 광학 교차 전환·촬영 지연 개선을 주장하지 않으며 0.15의 근거와 한계가 계속 적용됩니다.

## 검증

최종 로컬 기록은 `output/photon-v0.16.0/`에 있습니다.

- 앱·프로젝트 JVM 실행 194회, 실패·오류·생략0. 네이티브 호스트 8/8 통과이며 이 버전에서 네이티브 렌더 소스는 변경하지 않았습니다.
- Spotless, 디버그·릴리스 lint, APK 3종 빌드 통과. lint는 오류0, 경고22, 제안8이며 의존성·대상 업데이트, Compose modifier 순서, 코드로 만든 View 생성자, KTX, 상태 boxing을 포함합니다. UI 버전에 의존성·SDK 업그레이드는 넣지 않았습니다.
- 최종 기기 **13/13 통과**, `device-ui-final.log`. RAW AUTO 새 시작·재생성, 모드 탐색, 권한 진입, RAW Pro/HDR/강도 보존, 실제 격자·수평계·히스토그램 제어와 재개 중 샘플링, JPEG/DNG MIME·크기 제한 기록, 두 TIFF 바이트 순서·전체 센서 데이터 불변을 실제 셔터 없이 확인했습니다.
- 실제 최소/1.4배/8배 줌과 세 비율의 세로·가로 전환에서 네이티브 자르기를 통과했습니다. 상단·셔터와 네이티브 미리보기 사각형이 겹치지 않습니다. 실시간 미리보기 화면은 저장하지 않았습니다. 미지원 기기 경로는 코드·단위 검사이며 연결된 RAW 지원 폰은 지원 경로만 확인했습니다. 별도 미지원 실기기는 검사하지 않았습니다.
- 첫 기기 실행에서 히스토그램 줌 누락을 발견했습니다. 레이어 변환 명시 적용으로 수정해 메모리 흑/백/적 패턴의 1배/2배/8배/1배가 통과하고 중복 줌도 검출합니다. UI 검사는 시트가 나타날 때까지 기다리고 실제 완료 버튼을 쓰도록 동기화를 수정했습니다.
- 설치 개발 앱: versionCode22, `0.16.0-raw-auto-ui-debug`, 데이터 유지. 개발 APK SHA-256: `f3de6d134cd1c646e0e1693d8b64798cd774be480d876cb028f789dd7ea66168`. 다른 APK 해시는 `artifact-manifest.json`에 있으며 릴리스 APK는 당시 서명·게시하지 않았습니다.

추가 실제 사진은 촬영하지 않았습니다. 이 검사는 UI·구도 동작의 근거이며 새로운 실제 장면 자연스러움·노이즈 수용이 아닙니다. 사진 화질 한계는 0.15와 같습니다. 0.15 소스 기준본은 `output/photon-v0.16.0/baseline/`, 이전 APK·원본 사진은 버전별 로컬 출력 폴더에 보존합니다. 이 경로가 공개 첨부를 의미하지는 않습니다.
