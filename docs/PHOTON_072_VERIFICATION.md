# PHOTON 0.7.2 HDR 촬영 순서 개선

2026-10-23. 사용자가 0.7.1의 RAW 미리보기 수정을 확인한 다음의 후보 버전 기록입니다.

## 0.7.1에 남은 실패

실제 다음 셔터 시간은 1,023ms로 줄었지만 기준 프레임만 촬영했습니다. 설정 대기 450ms, 기준 JPEG 324ms, 복원 247ms였으며 짧은 노출은 생략했습니다. 최종 4080x3060 JPEG 1개와 EXIF·완료 상태는 확인했지만 HDR 성공은 아니었습니다.

## 검증 대상 변경

처음 AWB·초점 고정은 기다리되, 각 수동 센서 설정의 결과 대기를 JPEG 촬영·저장과 겹치게 했습니다. 다음 설정으로 넘어가기 전에는 해당 Future가 완료되어야 합니다. 기존 요청 옵션을 모두 복원하고 완료를 기다린 뒤 카메라를 다시 활성화합니다. 알고리즘·해상도·압축 설정·RAW 미리보기 수정은 유지했습니다.

이는 고정된 CameraX 1.6.2의 제어·요청 실행 순서에 근거합니다. `output/photon-v0.7.0/api-inspection`의 로컬 AAR 바이트코드에서 옵션의 동기적 추가, 순차 요청 실행기로 불변 변경의 등록, 후속 정지영상 요청에 변경 옵션이 합쳐지는 순서를 확인했습니다. Future 완료는 결과 태그까지 기다립니다. CameraX를 올릴 때는 이 가정을 그대로 옮기지 말고 요청 순서와 실제 EXIF 노출을 다시 확인해야 합니다.

합성 허용 여부는 여전히 실제 EXIF의 기준/짧은 노출 비율(시간×ISO)로 결정합니다. 두 장 확보만으로 HDR 합성 성공을 보고하지 않습니다. 시간 초과나 백그라운드 대기열 등록을 다음 촬영 준비 완료로 취급하지 않습니다.

## 실제 촬영 결과

AUTO는 두 노출을 확보했고(`manual_bracket_captured`) 실제 EXIF 비율은 **4.02521**이었습니다. 다음 셔터는 **1,297ms**로 목표를 97ms 넘었습니다. 잠금·설정 253ms, 기준 촬영 457ms, 짧은 노출 325ms, 복원 258ms입니다. 네이티브 HDR이 밝기 관계를 거부해(`exposure_mismatch`) 텍스처 처리한 기준 JPEG 1개를 저장했고, 총 1,647ms가 걸렸습니다. 따라서 이 후보는 **완전한 HDR 수용 조건을 충족하지 못했습니다**.

RAW3는 성공했습니다. 촬영 586ms, 다음 셔터 **587ms**, 합성 472ms, 쓰기 157ms, 총 1,249ms입니다. 합성 DNG 1개만 공개 저장했고 **원본은 공개 저장하지 않았습니다**. 변경 4,018,113픽셀, 채택 프레임 2개, 합성 7,373,129픽셀입니다. RAW 미리보기 축은 사용자가 정상이라고 확인한 상태입니다.

AUTO/RAW 메타데이터 읽기 검증은 **2/2 통과**했습니다(`real-metadata-readback.log`). 정확한 기록 URI, 크기, 소유권, 완료 여부, JPEG/TIFF 방향·치수를 확인했습니다. 실제 사진 자동 촬영이나 픽셀 검사는 하지 않았습니다.

다음 수정은 짧은 노출의 센서 완료와 자동 미리보기 복원을 겹치고 JPEG 톤 응답을 교정한 뒤 합성하는 것입니다. 실패한 실제 시간을 합성 영상 벤치마크로 대체하면 안 됩니다. 최종 수용에는 두 노출 확보, 다음 셔터 1,200ms 이하, 최종 결과 1개, 정확한 합성·대체 결과 보고가 모두 필요합니다. 위 출력 경로는 당시의 로컬 검증 자료입니다.
