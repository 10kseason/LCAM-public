# PHOTON 0.17.0 로컬 후보 검증

2026-10-24. RAW AUTO의 깊은 암부 합성, 큰 미리보기와 시스템 셔터음을 수정합니다. 공개된 0.16.1의 파일·태그는 그대로 보존하며 이 문서는 새 공개 릴리스의 증거가 아닙니다.

## 암부 HDR 수정

기존 `raw_hdr.cpp`를 직접 연결한 호스트 검사에서 결함을 재현했습니다. `usable()`의 black+1 하한은 노이즈 때문에 black 아래로 내려간 유효한 측정값까지 거절했습니다. 특히 가장 짧은 기준 노출의 20개 이웃 중 하나만 걸려도 셀 신뢰도가 0이 됐습니다. 또한 후보 가중치를 기준의 두 배로 제한해 잡음이 큰 짧은 프레임이 최소 20% 남았습니다.

- 유효성 하한은 센서 코드 0으로 변경합니다. black을 뺀 음의 측정값도 신뢰도·가중합 계산에 참여합니다. 포화 여유와 코드 0 거절은 유지합니다.
- 후보 가중치는 `trust / variance`로 계산합니다. 분산은 실제 노출비의 제곱으로 환산하며 기존 양의 분산 하한을 유지합니다. 기준 가중치의 인위적인 하한은 제거합니다.
- 정렬 승인·셀 전체의 움직임 거절·포화 보호·ROI·원본 불변 규칙은 유지합니다. 동노출 RAW DNG 및 SER Night 합성기는 변경하지 않습니다.

`native/lunacore/tests/raw_hdr_test.cpp`는 실제 구현을 링크하며 복제한 알고리즘을 검증하지 않습니다. 기존 12% 밝기 시험도 측광 1장과 비교하도록 바꿨습니다. 새 시험은 256×192 정지 장면, 측광 대비 노출 1/0.25/4, 10비트 센서 코드, CFA별 black 64/68/72/76, 독립 Gaussian 잡음 `var=S*x+O`를 사용합니다. `(S,O)`는 `(0.00002,0.000001)`, `(0.00012,0.000004)`, `(0.0005,0.000016)`이며 실제 기기의 ISO 값으로 해석하지 않습니다. 프로필마다 고정 seed 6개로 반복합니다. 정렬을 확인할 수 있는 무늬 주변에 1/1.6/3/6% 평탄 패치를 놓고 경계에서 떨어진 내부를 측정합니다.

아래는 세 잡음 프로필에서 얻은 **HDR RMSE / 측광 1장 RMSE** 범위입니다. 분산만이 아니라 편향을 포함한 선형 RAW 오차이며 낮을수록 좋습니다.

| 측광 밝기 | 수정 전 | 수정 후 |
| --- | --- | --- |
| 1% | 2.93~3.68 | 0.291~0.309 |
| 1.6% | 1.75~3.21 | 0.314~0.334 |
| 3% | 0.912~3.03 | 0.330~0.369 |
| 6% | 0.841~1.02 | 0.376~0.404 |

새 회귀 조건은 모든 밴드에서 `HDR MSE < 측광 1장 MSE × 0.6`입니다. 수정 전에는 실패하고 수정 후에는 통과합니다. 기존 움직임·포화 하늘·모호한 평탄 정렬·ROI·잘못된 메타데이터 검사도 유지하며, 코드 0으로 잘린 후보가 섞이지 않는 검사를 추가했습니다.

`RawHdrDeviceTest.deepShadowHdrBeatsMeteredSingleThroughSameRenderer`는 합성 RAW의 JNI 합성 결과와 측광 1장을 동일한 `renderNatural`의 게인·암부 강도·톤 설정으로 현상해 이상적인 무잡음 입력과 비교합니다. 센서 좌표를 읽거나 실사진을 저장하지 않습니다. 이는 실제 야외 A/B 10장을 대체하지 않습니다.

연결된 휴대폰에서 이 검사를 실행한 최종 RGB MSE 비율은 1/1.6/3/6% 순서로 **0.1039 / 0.1165 / 0.1483 / 0.1833**입니다. 대응하는 RMSE 비율은 약 0.322 / 0.341 / 0.385 / 0.428입니다. 렌더 게인은 측광 입력에 1.587401, 짧은 기준 단위의 HDR 입력에는 그 네 배를 적용해 같은 장면 밝기로 비교했습니다. JPEG 압축 전 Bitmap 비교입니다.

## 미리보기와 셔터음

`PhotonCameraLayout`은 시스템 UI·컷아웃을 제외한 카메라 화면의 72%를 미리보기 영역에 먼저 배정합니다. 세로에서는 하단, 가로에서는 측면에 조작부를 놓고 넘치는 항목을 스크롤합니다. 사진의 전체 구도와 비율을 유지하므로 실제 영상 주변에 여백이 생깁니다. RAW 확대의 네이티브 클리핑은 유지합니다. 좁은 조작부에서도 모드 제목이 버튼에 눌려 사라지지 않도록 제목과 버튼 줄을 분리했습니다.

AUTO·RAW·RAW AUTO·Night의 유효한 촬영 요청마다 `MediaActionSound.SHUTTER_CLICK`을 한 번 호출합니다. HDR 구성 프레임 수만큼 반복하지 않으며 저장 재시도에는 재생하지 않습니다. 앱에 무음 스위치는 없습니다. 준비·재생 호출의 동기 오류에는 촬영을 시작하지 않고 재시도를 안내합니다. 시스템 API는 비동기 출력의 성공이나 음압을 반환하지 않으므로 호출 성공을 실제 청취·법적 인증으로 간주하지 않습니다. [Android API](https://developer.android.com/reference/android/media/MediaActionSound)

2. 크로마 NR 및 디모자이크 품질 비교. 이번 수정에는 새 후처리를 추가하지 않았습니다.

5. 타일·서브픽셀 정렬, 행 병렬화, LUT 및 동노출 버스트 대안은 별도 성능·화질 검증 후 결정합니다.
