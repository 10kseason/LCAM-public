# PHOTON 0.12.0 로컬 후보 — AUTO 시작과 미리보기 히스토그램

2026-10-24. `LUNA_PHOTON_Codex_Handoff_v1.pdf`의 P1 히스토그램 항목을 이어 구현했습니다. 이 문서는 당시 로컬 개발 후보의 기록이며 공개 릴리스가 아닙니다.

## 동작

- 카메라 권한이 있으면 새로 시작할 때 AUTO를 바로 엽니다. 제품 탐색에 카메라 기능 확인 페이지가 없고 시작 시 자동 탐색도 하지 않습니다.
- 권한이 없으면 간단한 설명과 요청·설정 이동만 표시합니다. 거부 상태는 프로세스 재시작 뒤에도 유지하고 Android 설정에서 돌아오면 갱신합니다.
- AUTO 닫기·뒤로는 Activity를 종료합니다. RAW·SER Night는 촬영 설정에서 열고 AUTO로 돌아갑니다. 예전 진단 경로 이름은 저장 상태에서 읽을 수 있지만 AUTO를 표시합니다.
- 촬영 설정의 **밝기 히스토그램**은 기본 OFF이며 선택을 저장합니다. 미리보기 Y 코드값 64구간을 초당 최대 5회, 갱신당 최대 19,200표본으로 보여줍니다. 행·픽셀 간격, 버퍼 시작·끝, 선택한 중앙 비율 자르기를 지킵니다. RAW 노출계·포화 검출기·최종 톤 처리 JPEG 예측이 아닙니다.

## 구현 선택

수명 주기에 묶인 CameraX ImageAnalysis에 KEEP_ONLY_LATEST와 작은 320x240 요청 해상도를 사용합니다. 처리 제한·잘못된 프레임도 포함해 모든 ImageProxy를 finally에서 닫습니다. 주 스레드에는 집계 구간만 전달하며 프레임·집계는 저장·전송하지 않습니다. 활성 세션에서만 전용 실행기를 만들고 해제 때 종료합니다. 일시 정지 시 표시를 지우고 세대·비율 검사를 통해 해제·렌즈·자르기 변경 이후 늦게 도착한 결과를 거부합니다.

켜고 끌 때 세션을 다시 연결하므로 잠깐의 미리보기 중단은 예상 동작입니다. 먼저 일반 Preview+ImageCapture로 정지영상 해상도를 정하고 분석을 추가한 연결에서도 그 크기가 같을 때만 허용합니다. 미지원 조합, 정지영상 크기 변경, 비동기 분석 세션 오류는 일반 촬영으로 돌아가 설명을 표시합니다. 토글·재연결·다른 렌즈 선택으로 다시 시도할 수 있습니다. 비율 선택은 재연결 없이 자르기만 바꿉니다.

기존 AUTO/HDR/TextureGuard/DetailGuard, RAW 합성, SER Night 렌더·내보내기 알고리즘은 유지합니다. 새 권한·의존성은 없습니다. 진단 구현은 개발자 테스트용으로 남지만 제품 화면 진입점은 없습니다.

근거: [CameraX ImageAnalysis](https://developer.android.com/reference/androidx/camera/core/ImageAnalysis).

## 검증

- 최초 앱 JVM 검사는 신규 히스토그램 계산 4개를 포함해 통과했습니다.
- 전체 검증 통과: JVM 실행 158회, 네이티브 호스트 7개, Spotless, 디버그·릴리스 lint, 디버그·릴리스·기기검사 APK. lint는 오류 0, 기존 범주 경고 16개(SDK·의존성 및 기존 Compose 상태 사용), 참고용 KTX 제안 3개입니다.
- 기기 최종 **5개 통과**. AUTO 새 시작·재생성, RAW/Night 왕복, AUTO 뒤로 종료, 권한 UI 동작, 히스토그램 토글·자르기·일시 정지·재개·재생성, 처리·생략·잘못된 입력·소비자 실패에서 ImageProxy 닫기를 확인했습니다.
- 최초 기기 실행은 4/5였습니다. 다음 구성이 그려지기 전에 같은 이름의 접근성 노드를 재사용한 권한 테스트를 상태별 표식과 콜백 대기로 수정해 두 번째 실행에서 모두 통과했습니다. 두 로그를 보존했습니다.
- 권한 UI는 휴대폰의 실제 허용 상태를 바꾸지 않고 주입했습니다. 실제 OS 거부·취소·재허용 순환은 미검증입니다.
- 사용자의 명시적 승인 후 앱·테스트 APK 설치 성공, 설치 해시 일치, APK v2 서명 확인. 검사 후 AUTO를 다시 열었습니다.
- 디버그 SHA-256: `f3a7e1d45d3e5a4dc71e84ab7a994430de9b9255bfd89327a0a560045f9ac51a`.
- 연결 기기는 정지영상 해상도를 유지하면서 분석 스트림을 허용했습니다. 미지원 조합·비동기 HAL 거부 대체는 구현했지만 이를 거부하는 실제 하드웨어에서 검사하지 못했습니다. 히스토그램 ON 실촬영·지속 미리보기 FPS·배터리·발열·전체 지연을 주장하지 않습니다.
- 수정 전 소스와 이전 APK: 로컬 `output/photon-v0.12.0/baseline/`.
- 실제 셔터 자동 조작, 사용자 사진 픽셀 접근, 실시간 미리보기 화면 저장, 게시를 하지 않았습니다.
