# PHOTON 야간 모드 / 암부 근거 여유(Shadow Evidence Reserve, SER)

2026-10-23. PHOTON용 설계, 독립 정책 실험과0.11.0 앱 구현을 구분한다.0.11.0 로컬 후보에
전용 나이트 화면·Camera2 RAW 수집·GPU 합성/렌더러를 연결했다. 빌드·기기·실촬영 검증 상태는
[0.11.0 검증 기록](PHOTON_0110_VERIFICATION.md)이 기준이다. 배포된 v0.10.0 APK에는 없다.

## 목표와 차별화 지점

암부를 무조건 밝히는 대신, 추가 관측에서 검증한 **잡음 여유를 밝기 예산으로 환산**한다.
정지·신뢰 영역만 기준 프레임에 묶어 합성하고, 불확실·이동·신호 부족 영역은 기준으로 복귀한다.
PHOTON에 맞춘 구성과 판정 정책이다. 버스트·정합·잡음 가중치·톤 매핑은 알려진 기법이며
세계 최초나 독점성을 입증했다는 뜻은 아니다. [검토와 선행 자료](PHOTON_NIGHT_REVIEW.md).

## 정한 알고리즘

1. 동일 센서·실제 노출·ISO의 RAW 기준 한 장과 보조 두 장을 후보로 쓴다. 촬영 예산을 모르면
   추가 요청을 제출하지 않는다. 불확실한 상태에서 세션을 급히 교체하지 않는다.
2. black/white·CFA·센서·노출·timestamp를 검증하고 정합·움직임·희미한 구조 재현을 판정한다.
   JPEG에 RAW NoiseProfile을 적용하지 않는다. 중복 프레임은 새로운 관측으로 세지 않는다.
3. 채택한 보조의 역분산 가중치를 기준 이하로 제한하고, 평균을 기준에0.75 비율로 결합한다.
   모든 입력이 같은 분산이면 최종 계수는 기준0.5, 보조 각각0.25이다. 기준 기여는 최소0.5다.
4. 최종 계수의 분산에 프레임 간 공분산 상한을 포함한다. 모델 오차는 편향·합성 잡음과의 상관까지
   포함하도록 RMS 삼각 상한 `(sqrt(fusionVarianceBound)+sqrt(modelErrorMseBound))²`를 쓴다.
   보정 상한을 검증하지 못하면 기준으로 돌아간다. 검정의 양수 평균만으로 복원을 승인하지 않는다.
5. 추가EV를 `0.5*log2(referenceVariance/outputMseBound)` 이하로 제한한다. 신호 하한이
   충분한 암부만 허용하며, RGB 공통 이득은 가장 불확실한 채널과 headroom에 맞춘다.
6. 실제 렌더러는 black point·하이라이트·색 clipping·단조 톤 곡선과 그 미분까지 검증한다.
   이득을 공간적으로 정리할 때 불확실 영역 밖으로 번지지 않게 낮추는 방향으로만 적용한다.
   디테일을 지운 뒤 강한 샤프닝/생성형 복원으로 만들어내는 단계는 추가하지 않는다.

독립 동일 잡음의3장을 완전히 평균내도 같은 출력 잡음으로 허용되는 단순 선형 밝기 여유는
이상적인 예에서 약0.79EV다. 기준 기여를 유지하는 현재 정책의 이상적인 값은 약0.71EV이며,
상관 잡음·모델 오차·거절 영역에서는 더 작다. 실제 야간 DR 증가나 몇EV 복원을 보장하는 수치가 아니다.

## 구현된 실험의 경계

[`ser_policy.py`](../experiments/photon-night/ser_policy.py)는 고정 계수 선형 모델의 합성·추가EV
판정과 촬영 요청 예산 계산을 구현한다. 표준 Python3.10+만 사용하며 앱 빌드와 분리되어 있다.
정합 성공·잡음 보정·신호 하한을 외부에서 검증했다는 입력을 받는다. **그 입력을 검증하는
정합기/잡음 추정기, RAW demosaic·색 처리, 실제 tone renderer, GPU와 카메라 연결은 없다.**
적응형 clamp/warp/영상 기반 가중치의 출력 오차를 정확히 예측한다고 주장하지 않는다.

합성 잡음 실험은 독립 잡음과80% 공통 패턴 잡음 각각30,000회 관측을 만들어 밝기 이득 이후의
출력 잡음을 기준과 비교한다. 추가로 상관된 모델 오차30,000회, 움직인 후보 제외, 중복·미확인 보정·
검정 복귀, 수치 경계, 기준 기여, 입력 범위의 convex 결합과 예산 초과 거절을 검사한다.
**10개 테스트가 통과했다.** 센서/실사진 화질이나 속도 검증은 아니다. 초기 리뷰에서 찾은 극소 분산의
역수 overflow와 모델 오차 교차항 누락을 고쳤으며 회귀 실험에 포함했다.

```text
cd experiments/photon-night
python -B -m unittest -v test_ser_policy
```

## 0.11.0 앱 구현과 경계

- 홈 또는 AUTO 옵션의 **SER 나이트샷**으로 전용 화면에 진입한다. 후면1×,4:3,
  4080×3060 고정이다. 진입 때 물리 센서 프리뷰+RAW 세션을 미리 열어 셔터 때 재연결하지 않는다.
- 신선하고 안정된 노출/색/초점 결과를 동결해 동일 노출 RAW3장을 요청한다. 노출은50ms로
  제한하고 지원 범위 내 ISO로 보상한다. 촬영 예산 예측이 부족하면1장만 요청한다.
  ISO 증가는 추가 광자나 화질 향상 근거로 세지 않으며, ISO 상한이면 더 어두울 수 있다.
- `ser_night.cpp`가 Bayer 짝수 정합, 타일별 반대 패리티 잔차, 잡음·상관·모델 오차의 보수적인
  **추정치**를 만든다. 실측 보정된 상한은 아니므로 실제 MSE/SNR 향상을 보장하지 않는다.
  입력의 희미한 구조·움직임·포화·검정·중복과 불확실한 타일은 기준으로 복귀한다.
- `GpuSerNight`는 GLES3.1의 합성 → 이득 최소필터/기준 복귀 → 색 렌더3패스를 수행한다.
  기준 기여≥0.5, 추가 암부 이득≤0.35EV,4 CFA 채널 공통 이득과3×3 cell 최소값을 쓴다.
  이득이0인 cell은 RAW도 기준으로 복귀한다. CPU 참조 구현과 fallback을 함께 둔다.
- 렌더러는 방향 기반 Bayer 보간, 실제 물리 프레임의 WB+CCM, 연속적인 암부 곡선,
  sRGB를 사용한다. 강한 샤프닝·생성형 디테일·리사이즈는 없다. 단순 demosaic는 색 모아레 등
  한계가 있고, 합성 테스트 통과가 실제 천/머리카락 디테일 보존을 입증하지는 않는다.
- revision2는 실제 프레임의 잔여 lens-shading map을 Bayer/WB 전에 보간 적용한다.
  색 변환 뒤 채널별 clip 대신 중성축 chroma 압축과 공통 RGB 하이라이트 제한을 쓴다.
  연속 촬영 시 초점·WB를 최대2초만 유지하며 프리뷰 탭으로 즉시 해제한다. AE는 자동이다.
  전체 채널 포화 보호만으로는 녹색이 먼저 포화되는 중성광을 처리하지 못했다. revision4는
  센서 포화 근거가 있을 때만 WB/LSC 뒤 RGB를 첫 채널 포화 한계 `min(LSC×WB)`로 제한한 뒤
  CCM을 적용한다. 미포화 결과는 이전과 같고, 포화색은 달라질 수 있으며 손실 색 복원은 아니다.
  사용자는 수정본에서 모니터 흰색이 정상이라고 확인했다. SER ON 실제4장은 다음 촬영까지
  423–486ms,12.48MP GPU JPEG 한 장씩이고2장은 실제 SER 합성,2장은 기준 복귀였다.
  이는 해당 장면 회귀 확인이며 모든 야간 색·디테일·지속 연사를 보장하는 결과는 아니다.
- SER OFF는 기준 RAW1장 렌더링이다. 정상 경로는 JPEG97 한 장만 공개하며, 색 메타데이터나
  렌더 실패 시 기준 DNG 한 장을 보존한다. 처리 전 기준 DNG는 비공개에 완전히 쓴다.
  공개 저장 실패 시 비공개 파일을 남겨 수동 복구하며, 같은 UUID로 두 결과를 만들지 않는다.
- 기존 heavy-processing gate와2개 대기 슬롯을 공유한다. 새 NPU/학습 모델/상시 서비스는 없다.

## 속도·해상도와 검증 조건

- 사용자의1.2초는 **다음 촬영 접수까지**다. 이미 제출한 센서 요청·복원 완료 전에 버튼을 풀지 않는다.
  현재 AUTO 한 장954/860ms와 RAW3의 과거790ms는 야간 버스트 시간 근거로 일반화하지 않는다.
- GPU는 합성/톤/렌더 비용을 처리한다. 센서 노출·읽기·프리뷰 복귀 자체를 빠르게 만들지는 않는다.
- 이미 열린 RAW 세션의 실제 사용자 촬영으로 RAW 수신·프리뷰 복귀·대기열까지 측정한다.
  초점/저조도/열/지속 연사 전 범위의 p95/max 근거 없이 하드 실시간 보장을 표기하지 않는다.
- 기준 원본은 현재 확인된4080×3060,12.4848MP다. 현 폰의 공개 API에는16MP급 원본 경로가
  없었다. [센서 조사](PHOTON_RESOLUTION_PLAN.md). 확대 보간을16MP 촬영으로 표기하지 않는다.
- 한 장 결과 저장, 기존 보정 ON/OFF, 프리뷰·RAW 센서 일치와 저메모리 복귀를 유지한다.

실기기 암부 화질·야간1.2초·색·halo·지속 연속촬영의 현재 근거는0.11.0 검증 기록을 따른다.
